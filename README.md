# 📡 OpenWRT Dumb Access Point & Wireless Client Monitoring

*A lightweight monitoring web application for OpenWRT access points and wireless client visibility.*

<br>

> Vibe coded using Claude Opus 4.7

</div>

---

## ✨ Features

<table>
<tr>
<td width="50%">

### 📶 Multi-Router Monitoring
Monitor the status and availability of multiple OpenWRT routers from a unified interface.

### 📡 Signal Integrity Tracking
Track RX/TX signal integrity for both access points and connected wireless clients.

</td>
<td width="50%">

### 📝 Unified Logging
Centralized logs for system overview, diagnostics, and troubleshooting.

### 🔌 pfSense REST API Integration
REST API integration for pfSense 2.7.2 to provide additional wireless client information.

</td>
</tr>
</table>

---

## 🛠️ Overview

This web application is used for monitoring the following:

- OpenWRT router status
- Wireless client connectivity
- Access point signal health
- System and troubleshooting logs
- Additional wireless client data from pfSense
