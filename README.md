OpenWRT Dumb access point and wireless client monitoring. Vibe coded using claude Opus 4.7

This web app is used for monitoring the following:

1. Status of multiple openWRT routers.
2. Signal integrity RX/TX for APs and clients.
3. Unified logs for system overview and troubleshooting.
4. REST API for Pfsense 2.7.2 for additional wireless client information.
